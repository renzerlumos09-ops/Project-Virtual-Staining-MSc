| 2026-09-07 | mvp1_smoke   | 验证第二轮方案改进架构的核心假设：旧工作（半监督 CycleGAN + Pyramid Loss）正向出现白板坍缩，。<br />本方案改用「冻结编码器 + Proj 残差筛选 + 单边 FastCUT」结构，检验： <br />1. 全流程能否跑通（数据加载 → 冻结特征 → 生成 → 各项损失 → 反向传播）； <br />2. 结构信息是否经 PatchNCE 约束保留在生成图中。 | 编码器：冻结 ImageNet 预训练 VGG16；<br />Proj 模块：对高层特征做两次 stride-2 卷积，与编码器输出 S 相加后经 FeatureDecoder解码为 fake_B；<br />结构约束：PatchNCE（冻结特征空间）；<br />对抗约束：单边 GAN，LSGAN，判别器独立优化器 + TTUR；<br />规模：1 epoch，200 张样本，batch 1，仅为验证管线。 | smoke test 通过：无白板迹象，G_NCE 正常下降，D 偏弱需监控    |
| 2026-09-08 | mvp1_fastcut | 在 smoke test 验证管线后，进行首轮正式训练（5 epoch，10000 张样本，batch 2）；<br />正式检验核心假设：冻结 VGG + Proj 残差 + 单边 FastCUT 结构能否消除白板坍缩、 保留 AF 结构信息，并学会 IHC 画风。 | 与 smoke test 相同架构，仅扩大数据量与训练轮数。             | 5轮先验训练，白板坍缩没有复现，G_NCE 由 5.39 收敛至 ~1.2，结构保；<br />D判别器过强，Proj筛选功能失效，实验结果趋同于消融实验C |
| 2026-09-08 | mvp1_tuned   | 对输入判别器的真/假图像同步施加高斯噪声并线性退火；<br />模糊 Ground Truth 与虚拟染色图像的分布边界、延缓 D 收敛，为 G 争取画风学习窗口； G 的梯度始终走未加噪的干净AF，配合 TTUR。 | TTUR：$lr_D$=0.2 $lr_G$；<br />instance noise：线性退火0.3$\rightarrow$0;<br /> $\lambda_{distill}$ : 10$\rightarrow$1. | 输出图像成功学习目标风格映射：白底 + 蓝紫色苏木精细胞核 + 棕色 DAB 显色斑块；<br />Proj 残差三组损失仍迅速归零并恒等，   Proj 等效恒等，说明残差筛选需要更高语义的编码器特征驱动，结论支撑 MVP-2（IHC 域 MAE 预训练编码器替换 VGG）的必要性；<br />MVP-1 通过。已知局限：无配对设定下 DAB 显色位置属于画风先验的合理生成， 蛋白定位正确性需 MVP-2/MVP-3 的语义约束验证。 |
