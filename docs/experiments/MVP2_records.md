# 实验记录（MVP-2）

| 日期       | 实验         | 目标                                                         | 设计                                                         | 结论                                                         |
| ---------- | ------------ | :----------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 2026-09-15 | mvp2_mae_smoke | 验证 MIM 预训练管线全流程跑通：数据加载 → 随机遮挡 → 编码 → 解码重建 → 遮挡区 L1 → 反向传播 → 存图/存权重。 | SimMIM 式掩码图像建模：512×512 输入，16×16 grid（32×32 块）随机遮 50% 置中灰；<br />trainB 前 64 张，batch 8，1 epoch，ImageNet 初始化；<br />规模仅为验证管线。 | smoke test 通过：6s 跑完全流程无报错，重建图与权重正常落盘；<br />可上正式训练。 |
| 2026-09-16~18 | mvp2_mae_ihc（run 名 mae_ihc_v1） | 正式预训练 IHC 域语义编码器，替换 MVP-1 的 ImageNet 锚点（对应 RQ2：ImageNet 特征不含染色语义，Proj 恒零的阴性对照已存在）。 | 与 smoke 同架构；<br />trainB 全部 52,303 张，batch 4 + AMP，30 epoch，AdamW lr 1e-4 + cosine 退火；<br />产出 `mae_encoder_epoch30.pth`（VGG16 features state_dict 格式）。 | 反馈良好：loss 0.1241 → 0.1074 缓降趋稳；<br />epoch 10 起重建图达标——核形态、腺体轮廓可辨，DAB 显色区域位置正确（L1 均值倾向致饱和度偏淡，属预期，重建保真度非交付物）；<br />编码器权重产出，具备下游替换条件。 |
| 2026-09-25 | mvp2_ihc_fastcut | RQ2 判定：mae_ihc_v1 编码器灌入 FrozenVGG 冻结后，重跑 mvp1_tuned 同配置快速实验，检验 Proj 是否激活、画质是否改善。 | 同构替换，接口零改动：`--encoder_weights` 加载域内权重，`raw_input` 分支跳过 ImageNet 归一化；<br />3+1 epoch，10000 张，batch 2，instance noise 与 TTUR 配置同 mvp1_tuned。 | **有价值的失败**：fake_B 黑色背景被"锚死"——锚点强迫其保持黑色，细胞内部被漂白；Proj 三组损失依旧恒零（epoch 2 已 0.000/0.001/0.000）。<br />根因：MIM 预训练只用了 trainB（IHC），编码器特征空间只认识 IHC 的样子；AF 输入属域外样本（OOD），在锚点空间中提取不出潜在语义表征。<br />决定性结论：**冻结锚点的特征空间对最终输出有一票否决权**——锚点不认识的内容，G 与 PatchNCE 如何优化都无法映射。<br />行动：预训练数据改为 AF+IHC 双域（trainA+trainB，104,595 张），进入 v2 设计（mae_dual_v1）。 |
| 2026-10-03~07 | mvp2_mae_dual（run 名 mae_dual_v1） | 修复 ihc_fastcut 暴露的单域 OOD：在 AF+IHC 双域上重训编码器，使锚点特征空间同时覆盖两种"语言"。 | 架构与配置同 mae_ihc_v1；<br />数据改 trainA+trainB 混合 104,595 张，batch 8 + AMP，累计 18 epoch（夜间分段续训，`--resume` 加载权重）；<br />产出 `mae_encoder_latest.pth`。 | **验收通过**：AF 与 IHC 重建的腺体结构均成功可辨——AF 背景/腺腔回归深色，IHC 白底保持、DAB 显色位置与形态正确；<br />中期曾出现 AF 偏亮、IHC 偏暗的亮度欠校正，随训练自然收敛；残留亮度差距源于 L1 损失倾向预测条件均值（mean-seeking），属像素级重建的固有上限，不代表特征语义缺失；<br />预训练交付物是 encoder 特征而非重建图像：双域语义已学会，不再重训，权重接入下游 mvp2_dual_fastcut 翻译实验。 |
