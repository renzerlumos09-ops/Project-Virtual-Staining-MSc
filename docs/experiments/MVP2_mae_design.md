# MVP-2 MAE 预训练设计文档 · v1（IHC 单域版）

> 版本：v1.0（2026-09-22 定稿，2026-09-25 完成训练与下游验证）
> 状态：已完成。其失败教训直接催生 v2（AF+IHC 双域版，mae_dual_v1），另文阐述。
> 关联文档：MVP2_设计说明.md（RQ2 总体策略）、MVP2_records.md（实验记录）

## 1. 动机

MVP-1 留下一个阴性对照：冻结 ImageNet VGG16 特征下，Proj 残差三组损失（distill / pyramid / sparse）迅速归零并恒等，残差精修模块等效不存在。诊断结论是：ImageNet 自然图像特征不含染色语义，Proj 没有可筛选的对象。本设计的任务是**自训一个含 IHC 染色语义的编码器**，替换 ImageNet 锚点，使 Proj 有可驱动的特征基础。

## 2. 方法选择：为什么是掩码图像建模（MIM）

候选方案为对比学习（MoCo / SimCLR 类）与掩码图像建模（SimMIM / MAE 类）。选择 MIM，三条理由：

1. **硬件约束**：对比学习依赖大 batch 或负样本队列，8GB 单卡 batch ≤ 8 下无法提供足够负样本；MIM 无负样本需求，小 batch 友好。
2. **机制同构**：MIM 的训练任务——从可见上下文预测被遮内容——与本项目的预测性编码框架在机制上同构。预训练本身就是在教编码器做预测编码。
3. **领域先例**：病理虚拟染色的监督工作普遍使用 VGG 特征作感知损失，VGG 特征对该任务的兼容性已有先例。

## 3. 架构设计

**同构替换，接口零改动。** 不重新设计架构：构造与 MVP-1 中 FrozenVGG 完全同构的 VGG16 features 编码器，预训练完成后权重直接灌入，三层特征 tap 不变：

- relu2_2（128ch @ 1/2 分辨率）
- relu3_3（256ch @ 1/4 分辨率）
- relu4_3（512ch @ 1/8 分辨率）

**预训练任务（SimMIM 式）**：

- 输入 512×512，归一化 [-1, 1]；
- 16×16 grid（每格 32×32 像素）随机遮挡 50%，遮挡区域置 0（中灰）；32px 块可覆盖细胞核尺度结构，50% 比例在上下文保留与任务难度间折中；
- 轻量解码器将编码器最高层特征重建回原图，**L1 损失只计算遮挡区域**——迫使模型从上下文推断缺失内容，而非恒等拷贝；
- 解码器仅服务预训练，训完即弃；交付物只有编码器。

**初始化**：ImageNet 初始化（52k 张对 MIM 偏小，低层边缘/纹理先验加速收敛）；`--init scratch` 保留作从零训练对照。

## 4. 训练配置

| 项 | mvp2_mae_smoke | mae_ihc_v1（正式） |
|---|---|---|
| 数据 | trainB 前 64 张 | trainB 全部 52,303 张（IHC） |
| batch | 8 | 4（+ AMP） |
| epoch | 1 | 30 |
| 优化器 | AdamW（lr 1e-4, wd 0.05） | 同左 + cosine 退火 |
| 单轮耗时 | 6 s | 约 3800~4500 s |
| 产出 | 管线验证 | `mae_encoder_epoch30.pth` / `mae_encoder_latest.pth` |

## 5. 接口约定（下游接入）

- 只保存 `encoder.features` 的 state_dict，格式与 torchvision VGG16 完全一致；
- 下游 `FrozenVGG` 增加 `weights_path` 参数：提供则加载域内权重覆盖 ImageNet 权重，随后照常冻结；
- 加载域内权重时启用 `raw_input` 分支：**跳过 ImageNet 均值/方差归一化**，直接以 [-1, 1] 输入（与 MIM 预训练时的输入分布一致）；
- 加载成功打印 `[FrozenVGG] loaded domain-pretrained weights from ...`，启动日志须见此行方可继续。

## 6. 验收标准与结果

| 标准 | 结果 |
|---|---|
| 损失持续下降并趋稳 | ✅ 0.1241（epoch 1）→ 0.1074（epoch 30） |
| 重建图呈现合理 IHC 结构（核形态、腺体轮廓），而非涂抹色块 | ✅ epoch 10 起达标，DAB 显色区域位置正确 |
| 30 epoch 完成，权重产出 | ✅ |

已知且可接受的偏差：重建饱和度受 L1 均值倾向限制（显色偏淡、细节偏糊）。重建保真度不是交付物，编码器特征语义才是，故不据此修改损失。

## 7. v1 的局限与教训（→ v2 双域版）

v1 在 mvp2_ihc_fastcut 下游验证中暴露出**决定性局限**：预训练数据只有 trainB（IHC），编码器特征空间只认识 IHC 的样子；AF 输入属域外样本，其特征在锚点空间中无语义，导致 fake_B 黑色背景被锚死、细胞内部被漂白（详见 MVP2_records.md）。

结论：冻结锚点的特征空间对最终输出有一票否决权，编码器必须在**双域**（AF + IHC）上预训练。此为 v2（mae_dual_v1）的设计起点。
